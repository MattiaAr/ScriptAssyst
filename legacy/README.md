# Legacy scripts

Questa cartella conserva gli script della versione precedente di ScriptAssyst e alcune utility di debug/configurazione.

Questi file sono archiviati per riferimento e non fanno parte della build di Dashboard AD v1.0. Non eseguire le utility di configurazione credenziali senza averne prima verificato il contenuto e il contesto di utilizzo.

- AD-ChatbotTecnico_v0.3.ps1: script monolitico legacy.
- Check-OURoot-Debug.ps1: utility di diagnostica OU.
- Fix-TrustedHosts.ps1: utility per TrustedHosts.
- Genera-CredentialFile_v2.ps1: vecchia utility credenziali; non sostituisce il setup corrente in v1.0/Setup.
